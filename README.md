# 🚀 Beginner C Programs Collection

![Project Preview](images/banner.png)

Welcome! This repository contains a collection of beginner-friendly C programs, ideal for those starting out with programming and looking to explore concepts such as loops, functions, conditionals, sorting algorithms, number system conversions, and simple terminal-based games.

---

## 📂 List of Programs

Click a filename to view the source code:

- [AbsoluteValue.c](AbsoluteValue.c) — Calculates the absolute value of a number.
- [AverageScore.c](AverageScore.c) — Calculates the average of scores or numbers.
- [BubbleSort.c](BubbleSort.c) — Bubble sort algorithm implementation.
- [CalculatingAge.c](CalculatingAge.c) — Calculates age from date of birth.
- [CalculatingDates.c](CalculatingDates.c) — Simple date-related calculations.
- [CalculatingGrossNetVat.c](CalculatingGrossNetVat.c) — Gross/Net/VAT calculator.
- [Calculator.c](Calculator.c) — A basic calculator with multiple operations.
- [EucliideAlgorithm.c](EucliideAlgorithm.c) — Euclidean algorithm for GCD.
- [EvenNumbers.c](EvenNumbers.c) — Prints even numbers.
- [FactorialAlgorithm.c](FactorialAlgorithm.c) — Calculates the factorial of a number.
- [FibonacciAlgorithm.c](FibonacciAlgorithm.c) — Prints Fibonacci sequence.
- [GiocoDadi.c](GiocoDadi.c) — Dice game simulation.
- [GiocoOca.c](GiocoOca.c) — Basic version of the board game “Game of the Goose”.
- [GuessNumber.c](GuessNumber.c) — Guess the number game.
- [MaxNumber.c](MaxNumber.c) — Finds the maximum number in a set.
- [MenuDecimalBinary.c](MenuDecimalBinary.c) — Decimal to binary converter.
- [MenuDecimalHexadecimal.c](MenuDecimalHexadecimal.c) — Decimal to hexadecimal converter.
- [MenuDecimalOctal.c](MenuDecimalOctal.c) — Decimal to octal converter.
- [MenuManagementBank.c](MenuManagementBank.c) — Mini banking management menu.
- [PositiveNumbers.c](PositiveNumbers.c) — Checks and processes positive numbers.
- [Pow.c](Pow.c) — Calculates powers (exponentiation).
- [PrimeNumbers.c](PrimeNumbers.c) — Checks or prints prime numbers.
- [PythagoreanTable.c](PythagoreanTable.c) — Generates a Pythagorean multiplication table.
- [RecursiveFunction.c](RecursiveFunction.c) — Example of recursion in C.
- [Square.c](Square.c) — Calculates the area or side of a square.
